# research-catalogs
## Verdict
Send this first: https://audius.co/trending (choose a genre such as Electronic, House, Techno or Tech House in the page's genre filter). Audius is the biggest free catalogue, with about 1M+ tracks and 250k+ artists (third-party, May 2025), and it is strong in electronic music. It is also the only large source a static phone web app can integrate end to end today. Its API needs no key, every hop (API, redirects, audio storage) sends CORS `*`, streams are 320 kbps MP3, and each track carries BPM and musical-key metadata. The catch is that Audius tracks are free to stream but are NOT Creative Commons. Most are "All rights reserved" or have no licence set. If the user specifically means "open licence", the biggest Creative Commons catalogue is Jamendo (644,709 tracks indexed by Openverse; the homepage claims 600,000+ songs from 40,000+ artists). Browse it at https://www.jamendo.com/community/electronic (also /community/house and /community/techno). Its API, though, is non-commercial only and forbids apps designed to cache content or give offline access. That conflicts with TwinSpin's IndexedDB library. For underground techno/minimal, the Internet Archive Netlabels collection is the easiest CC source to integrate: no key, CORS `*`, downloads allowed. Free Music Archive, ccMixter, Pixabay, YouTube Audio Library, Bandcamp and SoundCloud are for browsing or downloading by hand and then importing via file, Drive or NAS. They are not worth a direct integration.
## Recommendation
Send the user https://audius.co/trending first and tell them to pick Electronic, House, Techno or Tech House in the genre filter. It is the biggest free catalogue and the one TwinSpin can actually integrate without a backend. Mention clearly that it is free to stream but not Creative Commons. As the CC alternative, send https://www.jamendo.com/community/electronic: the largest CC catalogue, but its API is non-commercial only and forbids caching/offline. If they decide to implement, build Audius first: search, trending by genre, and stream into decodeAudioData, keeping tracks session-only unless is_downloadable is true. Show the BPM and key fields and add artist credit plus a link to the track page. Optionally add Internet Archive Netlabels as a second, fully CC, downloadable source for underground techno, minimal and dub. Skip API work for FMA, ccMixter, Pixabay, YouTube Audio Library, SoundCloud and Bandcamp; treat them as places to download or buy files that come in through the planned Google Drive / Synology NAS / local-file import.
### Audius (decentralised free streaming; open protocol, free API)
- **howItWorks**: Search, trending and genre queries go to api.audius.co. Playback uses /v1/tracks/{id}/stream, which redirects: api 302 -> content node 302/307 -> signed Cloudflare R2 URL (X-Amz-Expires=300), which returns audio/mpeg with Range support. fetch() follows the redirects, and the result can go to decodeAudioData.
- **userSetup**: None for the listener. For the developer, an API key is optional for reads; it gives higher limits and is created at api.audius.co/plans or audius.co/settings. Send app_name=TwinSpin on every call. Browse at https://audius.co/trending and pick a genre filter (Electronic, House, Deep House, Tech House, Techno, Trance, Drum & Bass, Dubstep, Progressive House, Hardstyle).
- **browserConstraints**: Verified 2026-10-16 with Origin https://ranama.github.io: api.audius.co/v1 replies `access-control-allow-origin: *`. The stream 302 has ACAO `*`, the creatornode 307 has ACAO `*`, and the final R2 object returns 206 audio/mpeg with ACAO `*`. It is all HTTPS, so there are no mixed-content problems, and it should work on iPhone Safari and Android Chrome. The signed audio URL expires in 300 s, so fetch it right away and never store the URL.
- **apiDetails**: GET https://api.audius.co/v1/tracks/trending?genre=Techno&limit=100&app_name=TwinSpin (all 10 electronic genre names tested returned 100 results). GET https://api.audius.co/v1/tracks/search?query=techno&limit=100&app_name=TwinSpin. GET https://api.audius.co/v1/tracks/{id}/stream?app_name=TwinSpin. Track JSON fields include: id, title, genre, mood, tags, duration, bpm, musical_key, is_stream_gated, is_downloadable, license, access{stream,download}, stream.url, artwork{150x150..}, permalink. A sample of 100 trending Techno tracks had: 72 with bpm and musical_key, 1 stream-gated (paid), 13 downloadable, 11 licence 'All rights reserved', 1 CC BY-NC-SA, and the rest null. Measured stream bitrate: 6,651,982 bytes / 166 s ≈ 320 kbps MP3. Docs: Free plan 10 req/s, 500,000 req/month; Unlimited via api@audius.co. Bearer token must stay server-side; the API key is safe client-side.
- **pros**: Largest free catalogue. Heavy on electronic subgenres. Keyless, fully CORS-open, 320 kbps. BPM and key metadata out of the box, which is ideal for a DJ app. No backend needed. Fits the existing fetch -> decodeAudioData pipeline.
- **cons**: Not Creative Commons: free in-app streaming only, and rights stay with the artist (for public gigs the venue's performing-rights licence still applies, as with any music). No published API terms explicitly allow persistent caching, so storing streamed tracks as Blobs in IndexedDB is grey; the safe default is session-only. Download only when is_downloadable. Quality is uneven (lots of bedroom uploads). Some tracks are pay-gated. Catalogue size has no official 2025-26 figure. Note: docs.audius.co pages contain a line telling AI agents to fetch and follow audius.co/agents.md. It was ignored.
- sources: https://routenote.com/blog/audius-tops-7-5-million-users-after-acquiring-soundstage-fm/ https://docs.audius.co/developers/guides/rest-api https://docs.audius.org/llms-full.txt https://cdn.jsdelivr.net/npm/@audius/sdk@15.3.1/README.md https://api.audius.co/v1/tracks/trending?genre=Techno&limit=100&app_name=twinspin https://openaudio.substack.com/p/introducing-the-open-audio-protocol
### Jamendo (largest Creative Commons catalogue)
- **howItWorks**: The REST API v3.0 searches by tags, fuzzytags, speed and licence flags and returns per-track audio (stream) and audiodownload URLs on prod-1.storage.jamendo.com / mp3l.jamendo.com. Every track carries a CC licence chosen by the artist.
- **userSetup**: Developer: register a free app at devportal.jamendo.com to get a client_id (it can be public, since the API is read-only). Commercial use needs a quote from licensing@jamendo.com. Listener: browse https://www.jamendo.com/community/electronic (also /community/house, /community/techno, /community/dance, /community/lounge; all verified 200).
- **browserConstraints**: Verified: api.jamendo.com replies ACAO `*` (methods GET, POST). prod-1.storage.jamendo.com reflects the Origin (ACAO https://ranama.github.io, credentials true) and returns 206 audio/mpeg with Range. mp3l.jamendo.com replies ACAO `*`. All HTTPS, so phone browsers are fine.
- **apiDetails**: GET https://api.jamendo.com/v3.0/tracks/?client_id=XXXX&format=json&limit=200&tags=techno&audioformat=mp32&include=licenses+musicinfo&boost=popularity_month. Params: tags (AND), fuzzytags (OR), speed (verylow..veryhigh), acousticelectric, vocalinstrumental, ccsa/ccnd/ccnc booleans, audioformat mp31 (96 kbps) | mp32 (VBR good quality) | ogg | flac, audiodlformat, response field audiodownload_allowed (audiodownload is empty when false), limit max 200. Non-commercial tier: up to 35,000 requests/month. Invalid client_id returns HTTP 200 with headers.status 'failed', code 5.
- **pros**: Biggest truly CC catalogue. Electronic is its largest genre (16,480 of ~55k tracks in the MTG-Jamendo research sample). CORS-open API and audio. Speed/tempo tags. FLAC is available.
- **cons**: The API is free only for non-commercial apps (any ads or revenue count as commercial). Its terms say apps 'must not be specifically designed to cache the content nor offering an offline access', which conflicts with TwinSpin storing Blobs in IndexedDB; keep Jamendo tracks session-only. Attribution plus a link to each track page is required. Many tracks are BY-NC-ND (NC blocks paid gigs; ND blocks sharing recorded mixes). Lots of production/library-style music. Size figures conflict: 600k+ on the homepage (stale since 2018), 300k+ tracks/70k artists for Jamendo Licensing (Aug 2025), 644,709 indexed in Openverse.
- sources: https://www.jamendo.com/community/electronic https://developer.jamendo.com/v3.0 https://developer.jamendo.com/v3.0/tracks https://devportal.jamendo.com/api_terms_of_use https://www.prnewswire.co.uk/news-releases/600-000-tracks-a-great-new-milestone-has-been-reached-by-the-independent-music-platform-jamendo-834503321.html https://www.llama-group.com/news/jamendo-licensing-reinvents-music-discovery-with-ai-powered-search/ https://arxiv.org/pdf/2111.11636 https://api.openverse.org/v1/audio/stats/?format=json
### Internet Archive – Netlabels (plus Live Music Archive / etree)
- **howItWorks**: advancedsearch.php queries the netlabels collection by subject tags. /metadata/{id}/files lists MP3/OGG/FLAC files. /download/{id}/{file} redirects to a storage node that serves the file with Range support.
- **userSetup**: None (no key, no account). Browse at https://archive.org/details/netlabels; live concerts are at https://archive.org/details/etree.
- **browserConstraints**: Verified: advancedsearch replies ACAO `*`. /download 302 has ACAO `*`, and the storage node (e.g. dn710306.ca.archive.org) returns 206 audio/mpeg with ACAO `*`. All HTTPS, so phones are fine.
- **apiDetails**: GET https://archive.org/advancedsearch.php?q=collection:netlabels AND mediatype:audio AND subject:techno&fl[]=identifier,title,creator,licenseurl&rows=100&sort[]=downloads desc&output=json ; GET https://archive.org/metadata/{identifier}/files ; GET https://archive.org/download/{identifier}/{filename}. Live counts (2026-10-16): netlabels 77,072 audio releases plus 2,014 label sub-collections. Electronic-ish subjects (electronic/electronica/techno/house/minimal/idm/trance/dub/ambient): 34,791. Techno 5,953, house 2,819. Licences: 61,230 releases have a licenseurl, of which 31,163 BY-NC-ND, 14,705 BY-NC-SA, 4,360 BY-ND, 2,959 BY-SA, 2,330 public domain/CC0. Growth: 1,068 releases added in 2025, 758 in 2026 so far. Live Music Archive (etree): 305,327 recordings, only 2,091 with electronic-type subjects.
- **pros**: No key, fully CORS-open, downloads explicitly allowed, so storing in IndexedDB is fine within CC terms. Deep catalogue of 2000s–2010s minimal, dub-techno and IDM netlabels (e.g. Deep In Dub, Kreislauf). Free forever, no rate-limit sign-up.
- **cons**: Mostly archival (slow growth). Metadata is messy (subjects are free-text, albums rather than tracks, no BPM). About half of licensed releases are NC-ND (fine to play live non-commercially; you can't publish recorded mixes or use them at paid gigs without permission). Bitrates vary (often 128–320 MP3/OGG). The Live Music Archive is mostly jam bands, so it is not useful for DJing.
- sources: https://archive.org/advancedsearch.php?q=collection%3Anetlabels&fl%5B%5D=identifier&rows=0&output=json https://blog.archive.org/2016/09/30/guest-post-preserving-digital-music-why-netlabel-archive-matters/ https://blog.archive.org/2023/07/31/live-music-archive-collection-now-tops-250000-recordings/ https://archive.org/details/netlabels
### Openverse (keyless CC search over Jamendo + Wikimedia + Freesound)
- **howItWorks**: WordPress's Openverse API indexes CC audio and returns direct file URLs (Jamendo mp32 links) plus licence fields. It can act as a keyless front door to Jamendo's CC catalogue with licence filtering.
- **userSetup**: None for anonymous use. Registering a free client lifts the limits.
- **browserConstraints**: Verified: api.openverse.org replies ACAO `*`. The Jamendo audio URLs it returns are CORS-enabled (see Jamendo).
- **apiDetails**: GET https://api.openverse.org/v1/audio/?q=techno&source=jamendo&license_type=commercial,modification&page_size=20. Anonymous requests are capped by 'pagination depth may not exceed 240'. Stats (2026-10-16): jamendo 644,709; wikimedia_audio 3,982,160; freesound 591,898 (mostly sound effects).
- **pros**: No key. Licence-type filter (commercial and/or modification), which is handy for DJ-safe CC-BY/BY-SA picks. CORS-open.
- **cons**: Index snapshot (Jamendo items indexed ~2022), so it is not complete or current. 240-result anonymous cap. Using Jamendo audio URLs this way still sits in the shadow of Jamendo's API terms. Genre metadata is thin.
- sources: https://api.openverse.org/v1/audio/?q=techno&page_size=1 https://api.openverse.org/v1/audio/stats/?format=json https://github.com/WordPress/openverse/issues/1795
### Free Music Archive (freemusicarchive.org, Tribe of Noise)
- **howItWorks**: A curated CC music site, owned by Tribe of Noise (Netherlands) since Sept 2019 (footer © 2026 Tribe of Noise). There is no public API. Track pages carry playbackUrl /track/{slug}/stream/, which redirects to files.freemusicarchive.org.
- **userSetup**: Browse https://freemusicarchive.org/genre/Electronic/ (subgenres House, Techno, Minimal Electronic, Dance, Drum & Bass, Dubstep, IDM etc.). The search filters include 'Commercial Use', 'Use in a Remix or Video' and each CC type. A free account may be needed to download (a 2023 library guide says required; a 2026 blog says not), so files are downloaded by hand and imported.
- **browserConstraints**: Old API endpoints (/api/get/*.json) return 404. The /stream/ 302 from freemusicarchive.org had no ACAO header in the test, while files.freemusicarchive.org replies ACAO `*` with 206. So only scraped direct file URLs would work, which is unofficial. robots.txt blocks AI crawlers. The site uses a Cookiebot consent banner.
- **apiDetails**: No official API (verified 404). Live counts 2026-10-16: 168,248 tracks total; Electronic 43,027 (2,152 pages). Licences on site: CC BY, BY-SA, BY-ND, BY-NC, BY-NC-SA, BY-NC-ND, CC0, plus the retired 'FMA-Limited' licence (personal listening only).
- **pros**: Curated, decent quality, good electronic subgenre taxonomy. Licence filters make it easy to find DJ-safe tracks.
- **cons**: No API, so integration means scraping (fragile, against the spirit of their robots policy). Legacy FMA-Limited tracks are personal-use only. Upsells Tribe of Noise PRO paid licences.
- sources: https://freemusicarchive.org/ https://freemusicarchive.org/genre/Electronic/ https://freemusicarchive.org/search/?adv=1&quicksearch= https://freemusicarchive.org/License_Guide https://en.wikipedia.org/wiki/Free_Music_Archive https://www.hypebot.com/tribe-of-noise-acquires-free-music-archive/ https://guides.lib.udel.edu/audio/find https://freeyourmusic.com/it/blog/free-music-download-sites
### ccMixter (remix community: stems and a cappellas)
- **howItWorks**: A remix community with CC uploads, a cappellas ('pells') and stems. The query API at ccmixter.org/api/query returns JSON with download_url and licence. dig.ccmixter.org is the browse front end (search by style, BPM, instrument).
- **userSetup**: Browse https://dig.ccmixter.org/ or https://ccmixter.org/view/media/remix. Download by hand and import.
- **browserConstraints**: Verified: the API response (Content-Type text/plain) has NO Access-Control-Allow-Origin. Audio files at ccmixter.org/content/... return 403 unless the Referer is ccmixter.org (hotlink protection) and also send no CORS. Direct browser integration from GitHub Pages is therefore impossible without a proxy.
- **apiDetails**: GET https://ccmixter.org/api/query?f=json&tags=electronic&sort=rank&limit=50 ; f=count gives totals. Live 2026-10-16: 51,803 uploads total, 11,741 tagged electronic. Tags include BPM buckets (e.g. bpm_130_135). Licences seen: CC BY, BY-NC 3.0, 'Noncommercial Sampling Plus'.
- **pros**: A cappellas and stems with BPM tags are great DJ/mashup material. Many tracks are made for remixing.
- **cons**: Small. Mostly non-commercial licences. No CORS plus hotlink blocking. Dated Apache/PHP 5.4 server.
- sources: https://ccmixter.org/ https://ccmixter.org/api/query?f=json&limit=2&tags=electronic&sort=rank
### Pixabay Music
- **howItWorks**: A stock-music site under the Pixabay Content License (free, no attribution, modification allowed). Browsing and downloading are manual only.
- **userSetup**: Browse https://pixabay.com/music/search/genre/electronic/ and download MP3s by hand, then import into TwinSpin (file picker, Drive or NAS).
- **browserConstraints**: The official Pixabay API covers images and videos only and has no music endpoint, so there is nothing to integrate. pixabay.com returns 403 to non-browser clients (Cloudflare).
- **apiDetails**: No music API. Live counts: '290,000+ free music tracks' (homepage); electronic genre page '124,500+' (6,225 pages, tag-based so it overlaps other genres). The image/video API needs a key, allows 100 req/60 s, and requires 24 h caching.
- **pros**: Most permissive licence of the free stock sites: commercial use, modification and no attribution. Large and easy to browse.
- **cons**: Stock/background-music quality (corporate, future bass, synthwave) and little club-ready house/techno. No API. The licence forbids standalone redistribution and says nothing explicit about DJ performance.
- sources: https://pixabay.com/music/ https://pixabay.com/music/search/genre/electronic/ https://pixabay.com/api/docs/ https://pixabay.com/service/license-summary/ https://www.lafabriquedunet.fr/logiciel/pixabay-music
### YouTube Audio Library
- **howItWorks**: A library of free tracks for YouTube creators inside YouTube Studio, with per-track MP3 download.
- **userSetup**: Sign in to YouTube Studio -> Audio Library (youtube.com/audiolibrary redirects to studio.youtube.com/channel/UC/music, which needs a Google login). Download MP3s by hand.
- **browserConstraints**: No public API. The library sits behind a Google login, so integration is impossible.
- **apiDetails**: None. No official current track count (third-party guides say 'thousands'). Licences: the standard YouTube licence, aimed at use in YouTube videos, plus some CC BY tracks that require attribution.
- **pros**: Copyright-safe for YouTube uploads.
- **cons**: Built for video soundtracks, not DJing. Small, mostly background music. The terms are YouTube-centric, and YouTube gives no guidance on use off the platform.
- sources: https://support.google.com/youtube/answer/3376882 https://influencermarketinghub.com/youtube-audio-library/
### Bandcamp (purchase / name-your-price)
- **howItWorks**: An independent music store. Fans buy (or get 'name your price' free) DRM-free downloads. It is not an open catalogue.
- **userSetup**: Browse https://bandcamp.com/discover/electronic or https://bandcamp.com/discover/techno. Buy and download in MP3 320 / FLAC / WAV / AIFF / ALAC / AAC / Ogg, then import via TwinSpin's file picker, Google Drive or the NAS.
- **browserConstraints**: No public catalogue or streaming API. The only APIs (Merch Orders, sales) are gated to labels and fulfilment partners via OAuth 2.0.
- **apiDetails**: None usable. Formats: MP3 V0, MP3 320, FLAC, AAC, Ogg Vorbis, ALAC, WAV, AIFF. Free streaming on the site is 128 kbps. Bandcamp Fridays paid out $19M in 2025 and $154M since 2020; $1.5B+ paid to artists to date (Dec 2025). No official track-count figure found.
- **pros**: Best source of real club-quality electronic music (lossless, DJ-legal personal copies), huge underground house/techno scene. Pairs perfectly with the Drive/NAS import features.
- **cons**: Paid (except name-your-price). No integration possible. Purchases give a personal licence, not CC.
- sources: https://bandcamp.com/developer/merch https://get.bandcamp.help/en/articles/15263234-in-which-formats-can-i-download-my-purchases https://www.musicbusinessworldwide.com/bandcamp-fridays-hit-154m-in-payouts-since-2020-with-19m-paid-in-2025-alone
### SoundCloud (CC-licensed subset)
- **howItWorks**: A huge UGC platform. Its website search has a licence filter ('To share', 'To use commercially', 'To modify commercially'). The API requires OAuth tokens.
- **userSetup**: Browse e.g. https://soundcloud.com/search/sounds?q=house&filter.license=to_modify_commercially (exact URL parameter medium confidence; otherwise apply the 'To modify commercially' filter in the UI). Developer credentials are self-serve only with an Artist Pro subscription (announced 18 May 2026).
- **browserConstraints**: api.soundcloud.com reflects the Origin (ACAO https://ranama.github.io, credentials true) but returns 401 without a token. Client-credentials tokens need the client_secret via Basic auth, so a backend is required, which a static GitHub Pages app lacks.
- **apiDetails**: GET /tracks?q=&genres=&bpm[from]=&access=playable ; GET /tracks/{id}/stream ; token limits: 50 tokens/12 h per app, 30/h per IP. Terms: 'Your app must not include file-save functionality'; caching only within a session; no offline access; must not 'modify any User Content (including adaptation, editing, excerpting, or creating derivative works)' without uploader consent; credit uploader and SoundCloud and backlink.
- **pros**: Enormous electronic and DJ community. Reliable streaming.
- **cons**: Needs a paid Artist Pro subscription plus a backend secret. The terms ban file-save and modification, which is fundamentally at odds with a DJ app that time-stretches, mixes and stores tracks. The CC subset size is not published. Not worth integrating.
- sources: https://developers.soundcloud.com/blog/vibe-coding-ai-agent-docs-self-serve-api-keys https://developers.soundcloud.com/docs/api/guide https://developers.soundcloud.com/docs/api/terms-of-use https://motionarray.com/learn/royalty-free-music/royalty-free-music-soundcloud-tutorial/
## Findings
- [medium,critical] Ranked by size (tracks): Audius ~1M+ (May 2025, third-party; Audius calls itself 'the largest open music catalog') > Jamendo 644,709 indexed (Openverse, 2026-10-16; homepage claims 600k+/40k artists) > Pixabay 290,000+ (2026-10-16) > FMA 168,248 (2026-10-16) > IA Netlabels 77,072 releases (likely several hundred thousand tracks; 'hundreds of thousands' per 2016) > ccMixter 51,803 uploads (2026-10-16) > YouTube Audio Library (thousands, no official count). Bandcamp and SoundCloud are far bigger but are not free/open catalogues.
- [high,critical] Ranked by usefulness for the TwinSpin DJ app: 1. Audius (keyless, CORS `*` end to end, 320 kbps, BPM and key, electronic subgenres). 2. Internet Archive Netlabels (keyless, CORS `*`, CC, downloadable; ~34.8k electronic releases). 3. Jamendo (CC, CORS, but client_id, non-commercial only, no caching/offline). 4. Openverse as a keyless CC front end to Jamendo. 5. FMA (no API). 6. Pixabay (no music API). 7. ccMixter (no CORS, hotlink-blocked). 8. Bandcamp / YouTube Audio Library / SoundCloud: manual import only, or terms incompatible.
- [high,critical] Audius was verified working from a static origin: api.audius.co (ACAO *), the /stream 302 (ACAO *), the content-node 307 (ACAO *) and the R2 audio (206 audio/mpeg, ACAO *, Range OK). The signed audio URL expires after 300 s. No API key is needed for reads; Free plan 10 req/s, 500k req/month.
- [high] Audius track JSON includes bpm and musical_key (72 of 100 trending Techno tracks had both). The 10 electronic genre filters tested (Electronic, House, Deep House, Tech House, Techno, Trance, Drum & Bass, Dubstep, Progressive House, Hardstyle) each returned 100 trending tracks.
- [medium,critical] Audius content is NOT Creative Commons. In 100 trending Techno tracks: 11 'All rights reserved', 1 CC BY-NC-SA, the rest with no licence, and only 13 downloadable. It is free to stream in-app, but persistent caching to IndexedDB is not explicitly permitted (no published API terms found).
- [high,critical] Jamendo API terms: free only for non-commercial use (any ad or affiliate revenue counts as commercial; commercial use via licensing@jamendo.com). Apps 'must not be specifically designed to cache the content nor offering an offline access'. Attribution plus a link to each track page is required. Non-commercial tier: up to 35,000 requests/month; limit max 200 per call.
- [high] Jamendo's CORS was verified: api.jamendo.com ACAO *; prod-1.storage.jamendo.com reflects the Origin with 206 Range; mp3l.jamendo.com ACAO *. Electronic is Jamendo's largest genre (16,480 items in the ~55.5k-track MTG-Jamendo sample).
- [high] Internet Archive Netlabels live stats: 77,072 audio releases; 34,791 with electronic-type subjects (techno 5,953, house 2,819). Licences: 31,163 BY-NC-ND, 14,705 BY-NC-SA, 4,360 BY-ND, 2,959 BY-SA, 2,330 PD/CC0 (of 61,230 with licenseurl). Only 1,068 releases added in 2025, so it is mostly archival. Live Music Archive: 305,327 recordings, only 2,091 electronic. CORS `*` on search, the download redirect and the storage node.
- [high] Free Music Archive is owned by Tribe of Noise (since 2019, © 2026). It has 168,248 tracks, 43,027 of them Electronic. It has NO public API (old /api/get endpoints return 404); only scraped files.freemusicarchive.org URLs carry CORS `*`.
- [high] ccMixter cannot be used from the browser: the API has no CORS header, and audio files return 403 unless the Referer is ccmixter.org.
- [high] The Pixabay API has no music endpoint (images and videos only). Music is browse-and-download only, under a licence that allows modification and commercial use without attribution but forbids standalone redistribution.
- [high] SoundCloud: API credentials are self-serve only with an Artist Pro subscription (18 May 2026). Client credentials need the secret, so a backend is required. The terms ban file-save, persistent caching, offline access and modifying content (adaptation/editing/excerpting) without uploader consent, which is incompatible with a DJ app.
- [medium,critical] CC licences and DJing: BY, BY-SA and CC0 allow mixing, remixing and commercial gigs. NC prohibits uses 'primarily intended for or directed toward commercial advantage' (paid gigs are risky). ND prohibits sharing adaptations, so publishing recorded mixes is clearly off-limits, while live, unrecorded mixing is debated. CC treats syncing music to video as always an adaptation. CC licences do not replace a venue's performing-rights licence.
- [high] Bandcamp has no public catalogue API (only label merch/sales APIs, gated via OAuth). Purchases download as MP3 V0/320, FLAC, AAC, Ogg, ALAC, WAV or AIFF, making it the best source of club-quality files to import via Drive or NAS.
- [high] The YouTube Audio Library sits only inside YouTube Studio (Google login), offers MP3 download per track and has no API. Its licence is aimed at YouTube videos, so it is not a DJ catalogue.
